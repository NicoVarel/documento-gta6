PASO A PASO

Tu primer Short de GTA VI
en 5 pasos

Seguí estos pasos en orden. Los prompts están preparados para este repositorio concreto y no usan instaladores de otras páginas.

1

Abre Claude Code en una carpeta nueva

Crea una carpeta vacía en tu computadora y ábrela con Claude Code. Necesitás una computadora Windows o Mac, conexión a internet y acceso a Claude Code. No hace falta saber programar.

🟠 Claude CodeAsistente que instalará y ejecutará el kitAbrir ↗
2

Pega este prompt y Claude prepara todo

El prompt descarga el repositorio oficial de Nico Varel, inspecciona sus instrucciones y prepara el entorno. La instalación de dependencias solo se hará con tu autorización.

Quiero instalar y utilizar exclusivamente este proyecto de GTA 6 Shorts:
https://github.com/NicoVarel/Skill-gta6-shorts

Habla siempre en español. Trabaja únicamente en una carpeta nueva llamada GTA6-Shorts-Nico.
1. Comprueba que la URL sea exactamente NicoVarel/Skill-gta6-shorts y descarga el repositorio mediante git clone o el ZIP oficial de GitHub. No uses scripts descargados de otras webs ni comandos curl|bash.
2. Antes de ejecutar nada, inspecciona LEEME.md, CLAUDE.md, instalar.py, requirements.txt, PROMPT.txt y los scripts que el instalador invoque. Comprueba dependencias, red, archivos que modifica y riesgos. No ejecutes código si encuentras algo sospechoso.
3. Explica qué herramientas faltan y cómo se instalarán. Solo instala desde fuentes oficiales y solicita permiso antes de realizar instalaciones o acciones que afecten al sistema. Nunca desactives el antivirus, ni solicites permisos de administrador sin una razón concreta.
4. Sigue la documentación real del repositorio. Utiliza un entorno virtual aislado y conserva los archivos originales.
5. Si ElevenLabs necesita una API Key, indícame cómo crear una clave restringida, pídeme que la guarde localmente en .env (nunca la pegues en el chat), añade .env a .gitignore y no muestres ni subas secretos.
6. Al terminar, muestra qué quedó instalado y dónde puedo iniciar Claude Code en esa carpeta. No generes todavía el video: primero confirma que la instalación y herramientas básicas funcionan.
7. Si algo falla, diagnostica e intenta una alternativa segura compatible, sin inventar resultados.

Ver la Skill oficial en GitHub ↗
3

Conecta la voz de ElevenLabs

Este kit usa narración generada con ElevenLabs. Creá una clave de API privada y guardala localmente: nunca la publiques ni la pegues en un chat.

Ayúdame a configurar ElevenLabs en este proyecto de forma segura. No me pidas que pegue mi API Key en el chat.
Verifica qué variable y formato utiliza el repositorio de NicoVarel/Skill-gta6-shorts (LEEME.md y env.ejemplo). Explícame cómo crear una clave restringida a Text to Speech, establecer un límite de uso y guardarla en un archivo local .env excluido de Git. Haz una prueba mínima de conexión sin imprimir secretos ni gastar créditos innecesariamente. Si falta la clave, detente y dime dónde guardarla localmente.

Cómo conseguir la API Key: 1) Abrí ElevenLabs e iniciá sesión. 2) Entrá a Developers → API Keys. 3) Crea una clave con permiso de Text to Speech y límite de uso. 4) Guardala donde Claude te indique, en .env, sin compartirla. La disponibilidad y uso comercial dependen de tu plan.
Ir a las claves de ElevenLabs ↗
4

Elige tu idea de GTA VI

Podés usar cualquiera de las cinco ideas de arriba o proponer la tuya. Claude investiga el tema, verifica datos y prepara el guion, las escenas y la voz.

Ya tenemos instalado el proyecto NicoVarel/Skill-gta6-shorts. Quiero un Short vertical original sobre GTA VI: [ESCRIBE AQUÍ TU TEMA].
Sigue CLAUDE.md y LEEME.md del proyecto. Investiga con fuentes oficiales o comprobables; separa los datos confirmados de rumores y no inventes mecánicas ni fechas.
Crea un guion de 30–40 segundos con gancho en el primer segundo, 5–7 escenas y subtítulos sincronizados. Usa las imágenes incluidas en el repositorio cuando su uso sea adecuado. Antes de generar voz, muéstrame el guion y las fuentes con enlaces, y verifica la configuración de ElevenLabs sin revelar la clave.
Genera el MP4 vertical siguiendo las herramientas realmente disponibles. Revisa fotogramas y audio, corrige errores y entrégame la ruta final, título y descripción para YouTube.
5

Claude crea y revisa el Short

El sistema genera un video vertical con imágenes de apoyo, animaciones, voz, subtítulos y música. Pedile que revise los fotogramas, la legibilidad y la coherencia antes de darlo por terminado.

📁 Según el LEEME.md del repositorio, el archivo final se genera en proyecto/salida/short.mp4. También podés consultar PROMPT.txt si querés el flujo propio del autor.

PREGUNTAS RÁPIDAS

Todo lo que necesitás saber

¿Tengo que descargar la Skill manualmente?

No. El prompt le pide a Claude Code que descargue el repositorio oficial y prepare la instalación. Debés autorizar cualquier instalación y verificar las herramientas necesarias.

¿Tengo que pagar?

El repositorio es público. Claude Code y ElevenLabs pueden requerir un plan o tener límites; revisá sus condiciones actuales. Python y FFmpeg son gratuitos.

¿Puedo hacer cualquier video de GTA VI?

Podés proponer temas nuevos, siempre que el contenido esté bien investigado y existan recursos visuales apropiados. El acabado dependerá del material y de las herramientas disponibles.

¿El kit incluye la clave de ElevenLabs?

No. Cada alumno crea su propia clave en ElevenLabs y la guarda de forma privada en su computadora, sin mostrarla a Claude en el chat ni publicarla.

¿Esos Shorts realmente tienen 32 millones de vistas?

La cifra del título del tutorial es un gancho de referencia. No implica que los ejemplos de esta página tengan esa cantidad de vistas ni garantiza resultados futuros.

¿Puedo usar imágenes oficiales de GTA VI?

El kit incluye imágenes de referencia del juego. Rockstar Games y Take-Two mantienen sus derechos. Antes de publicar, revisá las condiciones aplicables y usá las imágenes dentro de un video original con comentario propio.
